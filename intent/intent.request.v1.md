# Intent Core — Request (v1)

## Purpose
Make a clear and reasonable request for action, information, or cooperation.

## Core Objective
Ask for something to be done without implying fault or escalation.

## Structural Guidance
1) Brief context or reason for writing
2) Clear statement of the request
3) Optional timing or condition
4) Neutral closing indicating openness

## Required Elements
- The request must be explicit and actionable
- The request must be framed once (no repetition)

## Prohibited Patterns
- Implied blame
- Ultimatums
- Justifying the request emotionally

## Output Expectation
The message should clearly state what is being requested
and allow the recipient to respond or act without pressure.
