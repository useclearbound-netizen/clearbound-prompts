# Intent Core — Clarify / Correct (v1)

## Purpose
Correct an inaccuracy or clarify a misunderstanding.

## Core Objective
Align on facts without assigning fault.

## Structural Guidance
1) Reference the point of confusion or error
2) Provide the correct or clarified information
3) State the implication or correction
4) Close neutrally

## Required Elements
- Factual correction must be explicit
- No judgment about how the error occurred

## Prohibited Patterns
- “You misunderstood” framing
- Condescending explanations
- Emotional reactions

## Output Expectation
The message should resolve confusion
and restore shared understanding.
