# Intent Core — Set a Boundary (v1)

## Purpose
Establish or reinforce a clear personal or professional boundary.

## Core Objective
Define what is acceptable going forward.

## Structural Guidance
1) State the situation or behavior
2) Define the boundary clearly
3) Indicate expected change or limit
4) Close with a neutral consequence or expectation

## Required Elements
- Boundary must be explicit
- Language must be declarative

## Prohibited Patterns
- Emotional justification
- Apologizing for the boundary
- Threats or punishment framing

## Output Expectation
The message should feel firm, controlled, and unambiguous,
without hostility.
