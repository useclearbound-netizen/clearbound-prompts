# Intent Core — Put on Record (v1)

## Purpose
Create a written record of events, positions, or expectations.

## Core Objective
Document facts clearly for future reference.

## Structural Guidance
1) State the purpose of documenting
2) List relevant facts or timeline
3) Note current status or expectation
4) Close without requesting engagement unless necessary

## Required Elements
- Clear indication that this is for record-keeping
- Factual, time-bound statements

## Prohibited Patterns
- Emotional language
- Implicit threats
- Accusatory framing

## Output Expectation
The message should read as neutral documentation
that can be referenced later without reinterpretation.
