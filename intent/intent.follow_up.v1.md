# Intent Core — Follow Up (v1)

## Purpose
Prompt a response or action on a previously raised matter.

## Core Objective
Re-surface an existing request or issue without escalating tone.

## Structural Guidance
1) Reference prior contact or context
2) State current status
3) Restate the needed response or action
4) Close with a neutral next step

## Required Elements
- Clear indication this is a follow-up
- Reference to time, event, or prior message

## Prohibited Patterns
- Accusatory language
- Escalation threats
- Emotional frustration

## Output Expectation
The message should feel timely, appropriate, and procedural,
not impatient or confrontational.
