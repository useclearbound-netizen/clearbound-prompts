# Format Rules — Message (v1)

## Purpose
Define structural and stylistic rules for short-form messages
(SMS, chat apps, internal messaging tools).

## Length & Structure
- Target length: 40–120 words
- 1–3 short paragraphs maximum
- Each paragraph should be 1–2 sentences
- Line breaks are allowed for readability

## Opening Rules
- Greeting is optional
- If used, keep it brief (e.g., “Hi,” or name only)
- No formal salutations

## Body Rules
- State the point quickly
- Prioritize the key request or clarification
- Avoid background explanations unless essential
- Use plain, direct sentences

## Closing Rules
- Sign-offs are optional
- If included, keep minimal (e.g., “Thanks”)
- Do not restate the entire request in closing

## Prohibited Patterns
- Email-style signatures
- Long explanations or justifications
- Formal closings or titles
- Excessive politeness markers

## Output Expectation
The result should feel natural in a messaging context:
clear, concise, and immediately readable.
